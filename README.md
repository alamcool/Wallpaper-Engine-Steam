## Wallpaper Engine Security Update (v2.8.42)

**What changed in August 2026?**
Wallpaper Engine 2.8.42 removed EXE-based application wallpapers from the Steam Workshop following a malware incident. A malicious wallpaper executable was discovered in the Workshop. The Wallpaper Engine team confirmed that Steam Workshop does not allow locking items from future updates, so application wallpapers were removed entirely as a precaution. Standard image, video, and web wallpapers remain unaffected and safe.

**Is Wallpaper Engine safe now?**
Yes. After the 2.8.42 patch, EXE-based wallpapers are no longer available on the Workshop. Only image, video, HTML/web, and scene wallpapers are supported. These cannot execute code and are safe.

## Wallpaper Engine Not Working (August 2026)

**Common fixes:**
- **After Windows update**: re-run the launcher to rebuild the wallpaper service. The wallpaper engine free download fixes this automatically.
- **Black screen**: update GPU drivers (NVIDIA 560.x, AMD 24.8.x or later), enable hardware acceleration in settings
- **Workshop not downloading**: confirm Steam subscription is active and Workshop sync is enabled in Steam settings
- **High GPU usage**: enable "Pause when fullscreen app detected" in settings to reduce load during gaming
- **Wallpaper disappears**: check that Wallpaper Engine is set to run at Windows startup in the settings
- **Audio visualizer not working**: make sure the wallpaper engine free process has access to system audio (Windows sound settings)
